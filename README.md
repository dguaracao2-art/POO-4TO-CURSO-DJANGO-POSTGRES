## Resumen de Actividades Realizadas

1. Se creó un repositorio público en GitHub para el desarrollo del proyecto.
2. Se configuró un entorno virtual de Python y se activó para el trabajo del proyecto.
3. Se instaló Django y se creó la estructura inicial del proyecto.
4. Se configuró el archivo `.env` para gestionar variables sensibles y parámetros de conexión.
5. Se configuró la conexión entre Django y PostgreSQL.
6. Se generaron e instalaron las dependencias del proyecto mediante el archivo `requirements.txt`.
7. Se ejecutaron las migraciones iniciales de Django para crear las tablas necesarias.
8. Se verificó el funcionamiento correcto del servidor local mediante la ejecución de `python manage.py runserver`.
9. Finalmente, se realizaron los commits y se publicó el proyecto en GitHub.
